# Read and parse HTML tables

This is a console for Data Analysis with Python that allows the user to generate code for basic reading and parsing data from HTML tables.

## Key feature
Single-click buttons for instantly creating syntactically correct code.

## Usage instructions
Click the desired button, and if any user input is required, an alert will indicate where to find the input element.
Here is the live link to [Parse HTML table](https://supravisor.github.io/Parse_HTML_table/).
